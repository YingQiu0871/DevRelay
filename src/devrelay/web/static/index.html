OpenCode endpoint

Only a loopback endpoint is writable here. The bearer token stays in DEVRELAY_OPENCODE_TOKEN; remote endpoints require a manual config edit. Workspace override, allow_unknown_workspace, profiles and executable/argv remain read-only.
