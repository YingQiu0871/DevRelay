SEMANTIC PROPOSITIONS (paraphrase)
P1  `dwDesiredAccess` is documented as "the requested access to the file or device, which can be summarized as read, write, both or neither (zero)", with the commonly used values `GENERIC_READ`, `GENERIC_WRITE` or both.
P2  `dwCreationDisposition` is documented as "an action to take on a file or device that exists or does not exist" and "must be one of the following values, which cannot be combined".
P3  `OPEN_EXISTING` (3) is documented as "Opens a file or device, only if it exists. If the specified file or device does not exist, the function fails and the last-error code is set to ERROR_FILE_NOT_FOUND (2)." — i.e. it neither creates nor truncates.
P4  The truncating disposition is documented separately as `TRUNCATE_EXISTING` (5), confirming that `OPEN_EXISTING` is not a truncating disposition.
