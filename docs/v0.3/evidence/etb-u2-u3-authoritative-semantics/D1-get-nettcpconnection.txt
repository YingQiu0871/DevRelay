SEMANTIC PROPOSITIONS (paraphrase)
P1  The cmdlet gets current TCP connections and exposes connection properties such as local or remote IP address, local or remote port, and connection state.
P2  `-LocalAddress` takes an array of local IP addresses, and the cmdlet gets the connections for the addresses that the caller specifies.  The parameter does not support wildcards.  Alias: IPAddress; position 0.
P3  `-LocalPort` takes an array of local ports, and the cmdlet gets the connections for the ports that the caller specifies.  The parameter does not support wildcards.  Position 1.
P4  `-State` takes an array of TCP states, and the cmdlet gets the connections that match the states the caller specifies; `Listen` is one of the accepted values.
P5  The cmdlet's documented Outputs type is `CimInstance`: a Microsoft.Management.Infrastructure.CimInstance wrapper for WMI objects, where "the path after the pound sign (#) provides the namespace and class name for the underlying WMI object".  This page does not itself name the underlying class.
