SEMANTIC PROPOSITIONS (paraphrase)
P1  The function "Retrieves the final path for the specified file", taking a file/directory handle.
P2  `FILE_NAME_NORMALIZED` (0x0) is documented as "Return the normalized drive name. This is the default."; `FILE_NAME_OPENED` (0x8) is "Return the opened file name (not normalized)".
P3  `VOLUME_NAME_DOS` (0x0) is documented as "Return the path with the drive letter. This is the default."; alternatives return volume-GUID, NT-device or no-volume forms.
P4  "A final path is the path that is returned when a path is fully resolved" — illustrated by a symbolic link `C:\tmp\mydir` pointing to `D:\yourdir` whose final path would be `D:\yourdir`.
P5  Recorded caveats: with `FILE_NAME_NORMALIZED` the function splits the path into components and queries each component's normalized name, and if the caller lacks access permission to any component the call fails with `ERROR_ACCESS_DENIED`; when using `VOLUME_NAME_DOS` the returned string uses the `\\?\` syntax.
