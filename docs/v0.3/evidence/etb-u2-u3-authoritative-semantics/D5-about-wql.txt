SEMANTIC PROPOSITIONS (paraphrase)
P1  A WQL WHERE statement establishes conditions for the data a SELECT statement returns, with the documented format `WHERE <property> <operator> <value>`.
P2  The documented comparison-operator table lists `=` as **Equal**, and lists `LIKE` separately as **Wildcard match** — so `=` is an equality comparison and is not the wildcard form.
P3  The documentation states that, when using the WHERE statement, the property name and value must be accurate.
P4  The documented example applies this to the class used by this round: `Get-CimInstance -Query "SELECT * FROM Win32_Process WHERE name='Notepad.exe'"`.
